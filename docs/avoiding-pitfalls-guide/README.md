## 如何读证据

正文内联短错误与结论所需上下文，原始工具参数、失败尝试和最终状态由来源坐标追溯。全量会话、机器覆盖清单和人工审阅报告只留在 `.agent-sessions/audit/`，已加入 Git 忽略；没有把原会话或个人绝对路径打进仓库。本批短证据足够，没有创建整会话归档。

历史命令是证据，不是现在应该自动执行的步骤。尤其 reset、update-ref、强杀进程、删除安装目录及发布操作，不能因为在历史里出现就再次运行。
